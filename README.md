# GeoLab

고등학생용 세계지리·한국지리 학습 웹사이트입니다.

- 과목별 단원 선택, OX 학습, 오답·문항 저장
- OX·기후·통계·기출·Notes·일조 자료 통합 검색
- 지도·기후·통계·기출의 원본 고급 기능을 자체 웹사이트 경로로 제공
- 스마트폰 설치형 PWA, 안드로이드 앱 빌드 지원 예정

**GeoLab 개발·기획 및 추가 학습 기능: © 안쌤**

GitHub Actions를 통해 기존 공개 학습 자료를 함께 제공하며, GeoLab 자체 제작 화면과 학습 콘텐츠를 지속적으로 확장합니다.
기존 외부 코드·자료의 이용 조건은 별도 보관된 라이선스 및 해당 자료의 이용 범위에 따라 관리합니다.
기술적 원자료 내려받기 경로와 원본 데이터 무결성 검사는 기존 동작을 유지합니다.

배포: 저장소 Settings → Pages → Build and deployment → GitHub Actions.

## OX 문항·정답·해설 관리 원칙

- **문항, 정답, 원본 X 해설은 한 글자도 재가공하거나 수정하지 않습니다.**
- 원본 OX 데이터 두 파일의 SHA-256 체크섬을 \`tests/ox-explain.test.cjs\`에서 검사합니다. 하나라도 다르면 배포 중단.
- 원본 X 문항 411개: 원본의 정정 해설을 괄호·강조 기호까지 있는 그대로 표시합니다.
- 원본 O 문항 765개: 원본에 별도 해설이 없는 경우 빈칸을 억지로 채우지 않습니다.
- 보충 해설은 \`app/ox-explain.js\`에 **문항 고유 ID·원문 완전 일치·정답 완전 일치** 조건과 함께 개별 등록한 경우에만 학생에게 공개합니다.
- 참고 문헌, 적용 교육과정, 해설의 표현을 문항 단위로 확인한 자료만 등록합니다. 일괄·단원 공통·정규식 자동 해설은 허용하지 않습니다.
- 2026년 기준 3학년은 2015 개정 교육과정(세계지리·한국지리), 1·2학년은 2022 개정 교육과정 적용. 수능용 기존 자료의 해설 검토는 2015 개정을 우선 기준으로 합니다.
- 정보가 시기·연도에 따라 변하는 문항은 통계 출처와 기준 연도 확인 전까지 보충 해설을 공개하지 않습니다.
- 현재 교과서 및 교육 자료와 대조한 2개 O 문항의 보충 설명만 공개하고, 나머지 O 문항은 개별 검토 대기입니다. 이 표시를 **전체 문항의 사실 검증 완료**로 오해하지 마세요.

교육과정 적용 근거: 교육부 고시 제2022-33호(2022 개정 고교 적용 연도), 국가교육과정정보센터, 2015 개정 사회과 교육과정, 2022 개정 사회과 교육과정.
